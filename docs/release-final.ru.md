## Область заявляемой эксплуатации и исключения

Подтверждена на указанном приборе автономная загрузка Web/Gateway/RNG с исправной согласованной CF после завершённого commit, возврат клиентских TCP P1/P2, один возврат LAN и явный первичный ввод новой CF со свежей внешней случайностью. Штатная политика — production-autonomous-v1/schema3: сохранение следующего seed до выдачи, восемь — диагностический порог, без service-arm на обычном запуске; неоднозначный commit закрывает RNG/Web без автоматического повтора.

Не заявляются физическое отключение внутри NV write/fsync, ресурс CF/NAND, физическое число NAND-записей, нагрузка восьми реальных портов или отсутствие потерь Modbus. Также эта аппаратная база не квалифицирует HTTPS/авторизацию, DHCP/DNS/смену адресов либо все отказы носителя. Локальные тесты HTTP/HTTPS/авторизации остаются локальными. Эти ограничения исключены из заявляемой области; они не создают новых обязательных серий для этого ограниченного выпуска. Для расширения заявлений нужны отдельные испытания.

Обязательные критерии закрыты: согласованный мастер/хеши, явный первичный ввод, совместимый пакет, сохранность конфигурации/RNG, согласованная серия автономности и целевой здоровый no-op. Уточнение ready/settled/error — отдельная диагностика при повторении неожиданных repair, не блокер этой области выпуска. Автоматическая первичная активация не добавлена. Публикация отдельно; приборы в этой работе не изменялись.
