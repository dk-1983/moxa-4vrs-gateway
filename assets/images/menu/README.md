# Menu illustrations / Иллюстрации меню

These images were rendered with the built-in image generation tool from
operator-supplied photographs of the running Gateway. Perspective, glare,
framing and background were adjusted for documentation. Visible menu labels,
selection and values were checked against the source photograph, except for
the explicitly substituted example address below.

Это иллюстрации, созданные встроенным генератором изображений по фотографиям
работающего Gateway, присланным оператором. Для документации исправлены
перспектива, блики, кадрирование и фон. Надписи меню, выбор и значения сверены
с фотографией; исключение — явно указанный ниже адрес-пример.

| File / Файл | Screen / Экран | Values / Значения |
| --- | --- | --- |
| `home.png` | Home / Главный экран | READY; 8/8 ready; Errors 0; Clients 0 |
| `main-menu.png` | Main Menu / Главное меню | Seven sections; Status selected / Семь разделов; выбран Status |
| `ports.png` | Ports / Список портов | P1–P5 visible, READY; P1 selected / Видны P1–P5, READY; выбран P1 |
| `configuration.png` | Config / Конфигурация | P1 selected; F5 Network / Выбран P1; F5 Network |
| `network-lan2.png` | Confirmed LAN2 / Подтверждённый LAN2 | Operator values retained / Значения снимка сохранены |
| `port-details.png` | Port 1: 1/4 / Подробности P1 | Operator values retained, including IP `10.0.2.13` / Значения снимка сохранены, включая IP `10.0.2.13` |
| `network-time.png` | Network Time / Настройки NTP | Synced, 1 h, Attempts 3; operator values retained / Synced, 1 ч, Attempts 3; значения снимка сохранены |

These are explanatory illustrations, not raw screenshots, packet captures or
additional hardware-test evidence. Example settings are not device defaults
and should not be copied into another installation without configuration review.
Runtime counters in a photograph represent that moment, not a benchmark.

Это поясняющие иллюстрации, а не необработанные снимки, захваты пакетов или
дополнительные доказательства аппаратных испытаний. Параметры примера не
являются настройками по умолчанию и не предназначены для бездумного переноса
на другое устройство. Счётчики на фото отражают конкретный момент, а не benchmark.
