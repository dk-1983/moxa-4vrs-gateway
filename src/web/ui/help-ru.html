Начало работы и управление

Новая установка без сохранённой конфигурации включает HTTP на LAN1. Существующая установка без поля протокола сохраняет HTTPS; обновление сохраняет выбранные настройки, включая Disabled. Выберите HTTP или HTTPS (TLS) в Web System или LCD System → Web Server. Работает только выбранный протокол. HTTP — без шифрования: пароль и данные передаются открыто; авторизация и локальное подтверждение восстановления остаются обязательными. HTTP рекомендуется для выделенной доверенной сети управления и остаётся режимом по умолчанию новой установки. HTTP передаёт пароль и данные без шифрования. HTTPS (TLS) остаётся доступной, но не рекомендуемой опцией на Moxa UC-7420-LX Plus. Обновление сохраняет явный выбор HTTP/HTTPS; конфигурация schema 1/2 без поля протокола сохраняет прежний HTTPS. Ограничение одним клиентом и хеширование пароля не защищают передаваемые по HTTP данные. Перед доверием сертификату HTTPS сравните SHA-256 с LCD. Смена протокола отзывает сессии: откройте новый адрес и войдите снова. При ошибке запуска нового режима возвращается прежний рабочий режим; управление через LCD сохраняется. Глобально допускается одно Web TCP-соединение, включая незавершённый handshake. Остальные закрываются до TLS; действующее соединение не вытесняется. Закройте другие Web-вкладки и дождитесь освобождения idle-соединения перед повторным подключением.

Для создания первого администратора введите временный код с дисплея и собственный пароль. Код действует три минуты, допускается не более пяти попыток. Это не пароль по умолчанию. После истечения срока запросите новый код через System → Web Server на панели. Последующий вход требует только пароль администратора, без имени пользователя. Длина пароля — 12–128 байт UTF-8: кириллица обычно занимает два байта на букву.

Автоповтор F2/F4 при удержании на целевом keypad provider ещё не квалифицирован.

Сохранение и подтверждение сети

Измените параметры порта и нажмите Сохранить. Отмена оставляет сохранённую конфигурацию прежней. Если настройки уже изменены через другую поверхность управления, устаревший черновик отклоняется: откройте страницу заново и повторите проверку.

Черновик сети → Проверить (было → станет, все четыре группы)
              → Применить → переподключиться при смене адреса
                          → Сохранить сеть до срока → записано
                          → Откатить / тайм-аут → прежняя сеть

Проверка сама по себе ничего не меняет. Keep подтверждает конкретную сетевую операцию; обычное Save отправляет изменение конфигурации. Принятый запрос ещё не доказывает успешную активацию: проверьте итоговое состояние. Не отправляйте новый сетевой черновик во время подтверждения предыдущего.

Настройка Gateway

Порты P1–P8 настраиваются независимо. Электрический режим, скорость, число бит данных, чётность и стоп-биты должны соответствовать подключённому устройству. TCP/UDP port — номер сетевой конечной точки, а не номер разъёма P1–P8. Bind IP ограничивает локальный адрес. Нестандартную скорость включайте только после проверки поддержки оборудованием.

В разделе Сеть четыре группы: LAN1, LAN2, общий маршрут по умолчанию и DNS. Static использует заданные IP, маску и шлюз. DHCP получает действующий адрес у DHCP-сервера; статические значения остаются в черновике. Маршрут по умолчанию выбирает интерфейс для адресов вне подключённых сетей. DNS Вручную использует DNS1/DNS2; DNS DHCP выбирает источник аренды. Выбор источника DNS не включает DHCP на этом LAN. Проверяйте все группы перед Применить.

В Системе доступны ручная установка часов, настройки NTP, проверка и остановка теста NTP. Выключенный NTP не означает недоверенные часы: время может быть установлено вручную или сохранять доверие после синхронизации. Состояние часов и результат проверки NTP — отдельные показатели.

Подсветка

System → Display управляет подсветкой локального дисплея. Off сохраняется при обновлении и не останавливает Gateway.

Подключения и кабели

У UC-7420-LX Plus LAN1/LAN2 — Ethernet, P1–P8 — настраиваемые последовательные порты, Console — отдельный RS-232 для управления. Одинаковая форма RJ45 не означает электрическую совместимость. USB, CompactFlash и PCMCIA — отдельные разъёмы.

Соответствующее руководство Plus указывает питание 12–48 VDC. Перед подключением проверьте маркировку реального прибора. Сначала соедините защитное/экранное заземление с подходящей заземлённой металлической поверхностью. На рисунке питания в руководстве SG — крайняя левая клемма в изображённом виде. Следуйте маркировке SG/V+/V− прибора, а не положению немаркированного повёрнутого разъёма.

Полный пример трёхпроводного RS-232

Для двух одинаковых последовательных гнёзд Plus в режиме RS-232 без аппаратного управления потоком перекрестите TXD/RXD и соедините сигнальную землю. Оба конца используют показанный выше вид в гнездо. Это схема между двумя указанными разъёмами, а не универсальный переходник RJ45/DB9:

Гнездо Plus P1                     Гнездо Plus P2
контакт 4 TXD ───────────────────→ контакт 5 RXD
контакт 5 RXD ←─────────────────── контакт 4 TXD
контакт 3 GND ──────────────────── контакт 3 GND
Контакты 1,2,6,7,8 не подключены с обеих сторон.

Для другого прибора сначала найдите вид его разъёма и таблицу сигналов, затем составьте карту обоих концов. Для аппаратного управления потоком нужна отдельно проверенная схема. Эти рисунки сверены с документацией, но не заменяют физическую проверку кабеля.

Console RS-232

Console RS-232: вид в гнездо, контакты сверху, защёлка снизу. 4 — TXD, 5 — RXD, 3 — GND; остальные сигналы управления приведены в столбце RS-232.

Ethernet LAN1/LAN2

Используйте Ethernet-кабель и сетевое оборудование Ethernet. На Ethernet-рисунке руководства Plus с выемкой защёлки снизу номер 8 расположен слева, 1 — справа; это отличается от serial-рисунка. Рассматривайте Ethernet отдельно, проверяйте маркировку и не применяйте последовательную схему кабеля.

Обслуживание и восстановление

CompactFlash в /var/hda хранит бинарные файлы приложения, конфигурацию и закрытые данные безопасности Web. Раннее восстановление installer находится в /etc/4vrs-installer и защищает запуск даже при отсутствии CF. Не извлекайте CF во время работы или записи.

В оболочке прибора, из каталога проверенного установочного пакета:

./4vrs-install
./4vrs-install --status

Установка запускает независимую операцию. Разрыв SSH сам по себе не доказывает успех или отказ. После переподключения прочитайте сохранённый результат:

/etc/4vrs-installer/recovery --status

Результат содержит этап и исход. Если требуется восстановление, сохраните результат и разберите причину перед повтором. Существующий recovery поддерживает явную операцию:

/etc/4vrs-installer/recovery --recover

Эта команда изменяет состояние установки: используйте её для конкретного прерванного обновления. Не удаляйте журнал вручную. Installer отключает автозапуск штатного Apache в своей транзакции, сохраняя его файлы; при откате возвращает прежнее состояние.

Перед обслуживанием подтвердите остановку Gateway в Системе. Это остановка приложения, а не ОС или питания. Перед отключением питания и извлечением накопителя выполните принятую на объекте процедуру завершения ОС. Для Console нужны правильный RS-232-кабель и проверенные параметры консоли конкретного прибора; это не Ethernet.

Для смены известного пароля: Система → Безопасность → Изменить пароль, текущий пароль и два ввода нового. Успешная запись завершает все сессии. Восстановление забытого пароля требует локального подтверждения и временного кода с дисплея. Старый пароль действует до надёжной записи замены.

Беспроводное расширение PCMCIA упоминается руководством Plus как дополнительное оборудование. Это не заявление о поддержке Wi-Fi или произвольных PCMCIA-драйверов продуктом 4VRS Gateway.

Диагностика и вопросы

Готовые порты и аварии?
Обзор сравнивает готовые порты с включёнными. Аварии — текущие проблемы жизненного цикла. Принято/завершено/тайм-ауты/восстановления/устаревшие ответы и максимум очереди — накопительные счётчики в диагностике, а не все текущие аварии.
Link down или тайм-аут?
Проверьте наблюдаемый link, выбранный LAN, адрес порта, режим линии и параметры второго устройства. Тайм-аут означает незавершённый в отведённое время запрос, но сам по себе не доказывает неисправность кабеля. Сравните CRC/ошибки кадров и события запуска перед изменением настроек.
Сохранено Enabled, но Web не Running?
Посмотрите локальную ошибку Web и выбранный IP. Отсутствие CF, нехватка энтропии, недоверенные часы, недоступный интерфейс или занятый порт могут препятствовать HTTPS. Владельца 80/443 сначала нужно определить; не останавливайте неизвестный процесс вслепую.
Предупреждение сертификата или новый отпечаток?
Сверьте текущий локальный отпечаток и выбранные IP. Смена адреса или продление могут изменить сертификат при сохранении закрытого ключа. Для сверки никогда не экспортируйте ключ.
Связь пропала после Apply?
Подключитесь к предложенному адресу и подтвердите Keep до срока. Если подключиться не удалось, дождитесь отката и вернитесь к прежнему адресу. Значения после неудачного обновления могут быть устаревшими.

HTTPS не рекомендуется для данного прибора из-за дополнительных вычислительных затрат и задержек подключения. Проверка пароля при авторизации создаёт временную высокую нагрузку — в испытаниях около 92% CPU, независимо от протокола.

После оптимизации обычная работа Web-панели создаёт небольшую нагрузку: в пользовательском HTTP-тесте процесс Web потреблял в среднем около 0,06% CPU, без учёта отдельного процесса проверки пароля. После входа интерфейс работает отзывчиво в обоих режимах.
