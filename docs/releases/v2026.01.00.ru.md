# v2026.01.00 — русский

Нативная автоматическая установка и сохранение подсветки для Moxa UC-7420-LX Plus.
Скачайте полный пакет `4vrs-gateway-v2026.01.00.tar.gz` и `SHA256SUMS`;
[инструкция установки](../installation.ru.md).

- `./4vrs-install` сохраняет собственные network/serial/NTP-настройки.
  `./4vrs-install --status` читает результат. Исправный повтор не перезапускает
  службы без необходимости; independent recovery защищает незавершённую
  транзакцию. Автоматической перезагрузки нет.
- **System → Display → Backlight → On / Off**: default On, F3 сохраняет,
  значение восстанавливается при запуске. Экран/кнопки работают при Off.
- Пройдены managed update/no-op, физическая подсветка и обычная перезагрузка;
  по одному точному instrumented immediate recovery и CF-present boot recovery.
  Это не все crash-фазы и не полная аппаратная квалификация.

**Ограничения:** первое развёртывание без Gateway, absent/late CF и физическое
снятие питания во время записи аппаратно не проверены. Владелец отложил тесты
с восстановительным носителем из-за отсутствия запасной CF; разрушать рабочую
установку для выпуска не требуется. Прочие DHCP/DNS/route/affinity и network
crash-границы сохранены в [статусе проверок](../validation.ru.md), не объявлены
новыми багами. Старый decoder не читает Off-поле: перед downgrade проверить
config и backup. Web — будущий выпуск. Assets v2026.00.01 не менялись.
