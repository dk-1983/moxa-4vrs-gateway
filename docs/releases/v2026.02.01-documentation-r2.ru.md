# Исправление документации v2026.02.01 — 12 сентября 2026

В первоначальной публикации оставались неполное дерево LCD, недостаточное описание Web и старые команды установки. Эти ошибки исправлены в main и архивах с суффиксом `docs-r2`.

- Руководства RU/EN содержат полное дерево LCD и Web, действия на всех семи страницах Web, подсветку, протокол, коды доступа и сертификат.
- В каждом руководстве 27 уникальных иллюстраций; изображение слева, путь справа. Проверены локальные ссылки и рендер галерей RU/EN.
- Инструкция установки содержит зависимости Ubuntu 24.04, загрузку и проверку архива, подготовку CF, отдельную первичную активацию RNG, запуск установщика и проверку конечного результата. Удалена привязка к прибору и UUID испытательного стенда.
- Pin `tools/cf-package.py` приведён к установщику, уже находившемуся в опубликованном мастере. Остальные скрипты мастера совпадают с опубликованными.
- Проверены распаковка штатным unzip, исполняемость worker, оба манифеста, загрузка всех 11 файлов пакета, отказы при повреждении пакета/комплекта, ABI пяти XScale ELF и синтаксис команд RU/EN. Проверки выполнены в контейнерах Debian 12 и Ubuntu 24.04; зависимости Ubuntu установлены по инструкции.

Установочный архив сохранён побайтно: SHA256 `624f807edb127977e09dde918460653b32b2b6f3590869080a6c144e6478844c`. Код в `src/`, исполняемые файлы мастера и вложенный установщик не изменены. Состав новых архивов и контрольные суммы проверены отдельно. Тег исходного выпуска сохранён; исправленная документация находится в main и выдаваемых архивах `docs-r2`.

Проверка документации не является новой физической установкой на прибор. Ранее подтверждённые аппаратные результаты и ограничения остаются прежними: [матрица выпуска](../release-final.ru.md). Потеря питания внутри NV-записи, ресурс NAND и нагрузка всех восьми физических портов этим аудитом не квалифицированы.
