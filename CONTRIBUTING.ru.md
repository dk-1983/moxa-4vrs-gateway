# Участие в проекте

[English](CONTRIBUTING.md) · Русский

Сообщайте о воспроизводимых ошибках и предлагайте изменения в
[Issues](https://github.com/dk-1983/moxa-4vrs-gateway/issues).
Для уязвимостей используйте приватный канал из [SECURITY.ru.md](SECURITY.ru.md).

## Сообщение об ошибке

Укажите модель устройства, версию продукта или коммит, транспорт и параметры
последовательной линии, ожидаемый результат, фактический результат и минимальную
последовательность действий. Различайте отказ сетевого подключения, исключение
Modbus и тайм-аут прибора. Удалите учётные данные и частные сведения о сети.

## Изменения исходников

Делайте изменения сфокусированными и объясняйте итоговое поведение. Сохраняйте
совместимость со старым компилятором XScale и целевой ОС. Потребление памяти
и ожидания должны быть ограничены; восстановление одного порта не должно
мешать работе остальных.

Запустите подходящие host-тесты из `tools/run-host-*-tests.sh` и запишите
результаты. Для изменений, зависящих от платформы, по возможности выполните
XScale-сборку и аудит ABI. Аппаратные результаты описывайте с указанием модели,
сценария и наблюдаемого исхода. Имитация на компьютере не является проверкой
на Moxa; отсутствие оборудования нужно прямо указать.

Используйте синтетические воспроизводимые тестовые данные. Не добавляйте
заводские прошивки, toolchain, архивы SDK, бинарники устройств, полные
конфигурации, пароли и частные журналы. Зависимости изготовителя для сборки
получают отдельно; см. [THIRD_PARTY.ru.md](THIRD_PARTY.ru.md).

Основной язык документации — английский, с русскими версиями README и
инструкции пользователя. При изменении пользовательского поведения обновляйте
оба языка. Планируемые функции обозначайте как планируемые; порядок установки
должен соответствовать реальному составу релизного пакета.
