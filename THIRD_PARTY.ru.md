# Сторонние материалы и материалы изготовителя

[English](THIRD_PARTY.md) · Русский

Лицензия MIT применяется к собственному коду и документации 4VRS Gateway,
если в файле не указано иное. Она не меняет лицензию сторонних материалов.

Прошивки Moxa, toolchain, архивы SDK и примеров, библиотеки, заголовочные файлы,
документация и бинарники сохраняют условия лицензий изготовителя. Закрытые
бинарники, скопированные с устройств, нельзя включать в публичный репозиторий
без установленных прав на распространение.

Проект хранит сведения о происхождении, версиях и контрольных суммах,
необходимые для воспроизводимой локальной подготовки. Получайте зависимости
отдельно из разрешённого официального источника и храните их в игнорируемой
Git папке `vendor/`.

Перед публичным выпуском исторические бинарные материалы `_legacy_materials/`
и `_live_reference/` должны быть исключены из публичной истории либо для них
должно быть установлено право распространения. Собственные выводы исследований
могут сохраняться без самих бинарников.

Старые руководства, SDK, прошивки и утилиты с диска Moxa в `_legacy_materials/`
являются локальными справочными материалами. Их наличие не означает разрешение
на публикацию. Публичная документация должна ссылаться на официальный источник,
когда он доступен, вместо включения локальных копий без подтверждённых прав.
