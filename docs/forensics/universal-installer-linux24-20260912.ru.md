# Адаптация универсального установщика: Linux 2.4

Аппарат: Moxa #4, UC-7420-LX, ОС 2.3, ядро
`2.4.18_mvl30-ixdp425`, адрес 10.0.2.19/20. Сравнительная платформа:
Moxa #3, UC-7420-LX Plus, ОС 1.6, Linux 2.6.

Универсальный launcher определяет поддерживаемое ядро и архитектуру и выбирает
соответствующий установочный пакет. Неизвестные сочетания отвергаются.
Проверяются отдельные ABI: Linux 2.4 использует `/lib/ld-linux.so.2`,
Linux 2.6 — `/lib/ld-linux.so.3`.

Аппаратные попытки выявили различия, отсутствовавшие в локальных тестах:

- Старый BusyBox не принимает `dirname --`. Launcher вычисляет каталог
  средствами shell; запуск из `/` по абсолютному пути проверен на приборе.
- Штатный Apache использует `/usr/sbin/httpd`, иной порядок аргументов
  и gate в `rc3.d`. Проверка принадлежности процесса сохранена.
- В заводском сетевом файле отсутствующая Wi-Fi-карта обозначена `eth0`,
  тогда как в Plus это `eth2`. Исключение остаётся ограниченным одним
  соответствующим статическим интерфейсом; произвольные пропуски запрещены.
- Старая `ifdown` поддерживает `--force`, но отвергает `-f`.
  Это подтверждено на приборе с `--no-act`: коды 0 и 1 соответственно.
- Linux 2.4 после отключения loopback сохраняет 127.0.0.1/8 без IFF_UP.
  Это отдельное остановленное состояние, а не готовность. После включения
  обязательны точный адрес, маска и IFF_UP, успешные hooks и receipt.

Первый отказ r3: `vendor-phase`, откат `verify-restored`.
r4/r5: `vendor-phase`, восстановление служб не завершалось автоматически.
При r5 обнаружен выключенный loopback с сохранённым адресом. Он восстановлен
штатной `ifup --force lo`, затем штатный recovery завершился
`verify-restored`. LAN ixp0 сохранил адрес и SSH-доступ. RNG повторно не
активировался и до следующей установки оставался ready/schema3/generation1.

После исправлений: 160 проверок сетевого запуска для каждого профиля
в normal и UBSan, все PASS. Проверены точные параметры forced ifdown,
остановленный loopback с сохранённым адресом и отказ при ложном успешном
включении без перехода в готовность.

Сборка r6 прошла vendor-phase, но остановилась на owner-start. Штатный
откат завершился verify-restored; Apache восстановлен, SSH и адрес сохранены.
Отдельный минимальный тест на реальном ядре подтвердил: socket и socketpair
AF_UNIX/SOCK_SEQPACKET возвращают -1/errno=94. Именно этот тип используется
сетевой службой; для Linux 2.4 требуется отдельная адаптация транспорта IPC.
Нельзя просто заменить тип на SOCK_STREAM без обработки частичных кадров,
очередей и сохранения проверок отправителя и жизненного цикла процессов.

Успех установки, перезагрузка, no-op, UART/Modbus и мастер CF пока не
утверждаются. r6 SHA256:
480f8baff504c82081b0f03faf4cf4928227b5e09e07f2ad90b48ce2a3d291e7.
Исходные журналы находятся в локальном `outputs/universal-installer`.
