# v2026.02.01 — окончательный комплект для рассмотрения

Исправлен pin мастера: он формируется из фактического gateway.tar.gz до обоих манифестов; распакованный ZIP проходит package.load и отрицательную проверку повреждения. В установщике добавлены несекретное объяснение no-op/repair и только читающий --decision-journal. Проверки здоровья сохранены; runtime и RNG не менялись.

Подтверждены 10/10 физических циклов после завершённого commit, один возврат LAN и отдельный ввод запасной CF. Критерий no-op закрыт: исторический журнал подтвердил platform verify, новый repair дал network-service-health, здоровый повтор — result3/no-op с сохранением Gateway/RNG PID и поколения. Историческая сетевая первопричина и неизменность Web PID не доказаны. Готово к выпуску в заявленной области. Не заявляются питание внутри NV write/fsync, NAND-ресурс, нагрузка восьми реальных портов и отсутствие потерь Modbus. Первичная активация остаётся явной.
