# Универсальный кандидат v2026.02.03 — результаты 12 сентября 2026

Это аппаратная проверка кандидата, не сообщение о публикации.

## Платформы и исправления

UC-7420-LX Plus с ОС 1.6/Linux 2.6.10 и UC-7420-LX без Plus с ОС 2.3/Linux 2.4.18 используют один архив. `sh install.sh --detect` выбирает профиль без установки; `sh install.sh` запускает соответствующий транзакционный установщик.

На Linux 2.4 аппаратно установлено отсутствие AF_UNIX SOCK_SEQPACKET. Для сетевой службы реализован SOCK_STREAM с фиксированными кадрами, обработкой частичного чтения, ограниченным ожиданием записи и закрытием повреждённого потока. Внутренняя унаследованная пара guardian/owner использует SOCK_DGRAM. Проверка UID и защищённого каталога сохранена. Linux 2.6 сохраняет SOCK_SEQPACKET. Web IPC на обеих платформах размещён в `/var/4vrs-web-ipc` в RAM.

Профили также учитывают имена интерфейсов, отсутствующую необязательную Wi-Fi-карту, старый `ifdown --force`, loopback DOWN с сохранённым адресом, пути Apache и ELF ABI. После остановки приложения повторный start восстанавливает управляемую сетевую службу. Установщик сообщает конкретную стадию отказа при остановке служб.

## Мастер CF и локальные проверки

27 сценариев мастера прошли normal/UBSan: два ELF-профиля, ext3 round-trip, сохранение существующего состояния, отказ при повреждении, подмене вложенного каталога ссылкой и прерванной записи. С итоговым pin normal повторён: 27 PASS. Проверка универсального архива подтвердила выбор платформы, отказ при смешанном ABI, повреждении, дубликатах и traversal, воспроизводимость и сохранение существующего файла результата.

Переносимый ZIP проверен после `unzip`: оба манифеста и SHA256 согласованы, worker исполняется и отказывает без параметров устройства, `package.load` принимает вложенный архив, повреждение архива и комплекта отвергается. Повторная сборка ZIP побайтно идентична. Физическая CF мастером в этой серии не форматировалась.

Сетевой транспорт проверен отдельными 31 проверками normal/UBSan; полная сетевая серия пройдена с обоими транспортами. Предыдущие ограничения испытаний сохраняются: нет квалификации потери питания внутри NV-записи, ресурса NAND и восьми одновременно нагруженных физических UART/Modbus. Эти результаты не доказывают отсутствие потерь Modbus.
