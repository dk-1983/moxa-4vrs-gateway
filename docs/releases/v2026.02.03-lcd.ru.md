Иллюстрация подготовлена по фотографии реального экрана. [Исходный снимок](../../assets/images/screenshots/lcd-gateway-stopped-v2026.02.03-original.png) сохранён отдельно.

`Gateway stopped` означает завершение приложения, а не выключение Linux. Перед физическим отключением питания завершите работу ОС. При `Shutdown failed` показана причина; F1 возвращает к меню. Если порты уже остановлены, возврат не запускает их заново: доступны просмотр состояния и диагностика, а изменение настроек заблокировано.

Новых пунктов Web-меню в этом изменении нет. Остановка из Web использует тот же процесс завершения Gateway; финальное сообщение остаётся на LCD.
