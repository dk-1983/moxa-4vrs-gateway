# v2026.02.03 — остановка Gateway и универсальная установка

[English](v2026.02.03.md) · [Установка](../installation.ru.md)

- LCD показывает `Stopping Gateway`, затем `Gateway stopped` или причину `Shutdown failed`. При ошибке F1 возвращает к меню. Остановка приложения не выключает ОС; перед снятием питания завершите её работу. [Фотография и дерево](v2026.02.03-lcd.ru.md).
- Безопасные права корня CF восстанавливаются при старте; RNG-файлы сохраняются.
- Web IPC находится в RAM `/var/4vrs-web-ipc` на обеих платформах.
- Один установочный архив поддерживает UC-7420-LX Plus, ОС 1.6/Linux 2.6.10, и UC-7420-LX без Plus, ОС 2.3/Linux 2.4.18. Профиль выбирается на приборе. Мастер CF содержит тот же архив.
- Для старой ОС адаптированы IPC сетевой службы, команды сети, пути Apache и ABI. После stop/start приложения восстанавливается управляемая сетевая служба.

Аппаратно проверены установка, stop/start, RNG и здоровый no-op на обеих платформах; на Linux 2.4 также возврат после перезагрузки ОС. Первая попытка обновления Plus завершилась services-stop и успешным откатом; конкретная причина осталась неустановленной, последующая проверка прошла. [Полный отчёт и границы](../forensics/universal-installer-final-checks-20260912.ru.md).

Локально проверены кадры IPC normal/UBSan, оба ELF-профиля, транзакционный установщик, 27 сценариев мастера normal/UBSan, распаковка ZIP и отказ при повреждении. Сохранены [ограничения предыдущей аппаратной серии](../release-final.ru.md): потеря питания внутри NV-записи, ресурс NAND, восемь нагруженных портов и отсутствие потерь Modbus не квалифицированы. Замеры Web 0,06%/92% относятся к прежним испытаниям Plus, не к новой Linux 2.4 платформе.

## Файлы и установка

- `4vrs-gateway-v2026.02.03-universal.tar.gz` — полный пакет. После распаковки на CF запустите `sh install.sh --detect`, затем `sh install.sh` из его каталога.
- `4vrs-cf-wizard-v2026.02.03-universal-ubuntu24.zip` — подготовка или обновление CF на Ubuntu 24.04.
- `4vrs-gateway-v2026.02.03-source.zip` — исходники и документация.
- `SHA256SUMS` — контрольные суммы выдаваемых файлов.

Следуйте [первичному вводу](../release-final-commissioning.ru.md). Новая CF требует отдельной явной активации RNG; исправную активную schema 3 повторно активировать не нужно. `result=100` означает продолжающуюся установку. Не запускайте её повторно до конечного результата. Прежние релизы и их пакеты сохраняются.
