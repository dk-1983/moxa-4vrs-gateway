# v2026.02.03 — Gateway shutdown and universal installation

[Русский](v2026.02.03.ru.md) · [Installation](../installation.md)

- LCD shows `Stopping Gateway`, followed by `Gateway stopped` or a `Shutdown failed` reason. F1 returns to the menu after failure. Stopping the application does not shut down the OS; shut down the OS before removing power. [Photo and navigation](v2026.02.03-lcd.md).
- Startup restores safe CF-root permissions without removing RNG state.
- Web IPC resides in RAM at `/var/4vrs-web-ipc` on both platforms.
- One installer supports UC-7420-LX Plus OS 1.6/Linux 2.6.10 and UC-7420-LX OS 2.3/Linux 2.4.18. It selects the profile on the device. The CF wizard includes the same archive.
- Legacy-OS network IPC, network commands, Apache paths and ABI are supported. Application stop/start restores its managed network service.

Hardware installation, stop/start, RNG and healthy no-op passed on both platforms; Linux 2.4 also returned after OS reboot. An earlier Plus update failed at services-stop and rolled back successfully; its specific cause remains unknown, while the subsequent check passed. [Evidence and limits](../forensics/universal-installer-final-checks-20260912.md).

Local checks cover IPC framing normal/UBSan, both ELF profiles, transactional installation, 27 CF wizard scenarios normal/UBSan, actual ZIP extraction and tamper rejection. [Prior qualification limits](../release-final.md) remain: power loss inside NV writes, NAND endurance, eight loaded physical ports and lossless Modbus operation are not qualified. Previous 0.06%/92% Web measurements apply to Plus tests, not the new Linux 2.4 platform.

## Files and installation

- `4vrs-gateway-v2026.02.03-universal.tar.gz`: complete package; extract on CF and run `sh install.sh --detect`, then `sh install.sh` from its directory.
- `4vrs-cf-wizard-v2026.02.03-universal-ubuntu24.zip`: Ubuntu 24.04 CF preparation/update wizard.
- `4vrs-gateway-v2026.02.03-source.zip`: source and documentation.
- `SHA256SUMS`: delivery checksums.

Follow [commissioning](../release-final-commissioning.md). New CF requires separate explicit RNG activation; healthy active schema 3 does not. `result=100` means installation is still running. Do not relaunch before a terminal result. Previous releases and packages are retained.
