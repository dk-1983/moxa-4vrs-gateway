# Установка и обновление — v2026.02.03

Поддерживаются UC-7420-LX Plus с ОС 1.6 / Linux 2.6.10 и UC-7420-LX без Plus с ОС 2.3 / Linux 2.4.18. Универсальный установщик выбирает профиль на приборе; выбирать ОС в мастере CF не нужно. Другие модели не квалифицированы.

Используйте полный установочный архив и мастер CF из [релиза v2026.02.03](https://github.com/dk-1983/moxa-4vrs-gateway/releases/tag/v2026.02.03).  Это установка приложения на CF, не обновление заводской ОС.

1. [Подготовьте новую CF или разместите обновление мастером Ubuntu 24.04](cf-wizard.ru.md). Полная очистка удаляет прежние данные; обновление сохраняет активную установку и RNG.
2. [Выполните установку, отдельную первичную активацию и проверку](release-final-commissioning.ru.md). Уже активная согласованная schema 3 не требует повторной активации.
3. [Проверьте результат установщика](release-final-commissioning.ru.md): запуск фоновой операции ещё не означает её завершение.
4. [Откройте руководство LCD/Web](user-guide.ru.md) и проверьте реальные запросы к подключённым устройствам.

Старые команды и хеши v2026.01.01 к этому пакету не относятся. Перед откатом проверьте совместимость схемы 3; полный возврат старого образа CF с RNG не поддерживается. [Проверенная область и ограничения](release-final.ru.md).
