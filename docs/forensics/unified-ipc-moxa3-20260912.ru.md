# Единый IPC-путь: аппаратная проверка Moxa #3, 2026-09-12

По просьбе пользователя обе платформы используют `/var/4vrs-web-ipc`. Каталог 0711, socket 0666, lock 0600; проверки владельца, inode и отсутствия активного чужого endpoint сохранены. Новая константа находится в web_ipc_endpoint.h, а не в платформенном профиле.

Moxa #3: UC-7420-LX Plus, vendor OS 1.6, Linux 2.6.10_dev-ixdp42x-arm_xscale_be. Подтверждено: /var — /dev/ram0 ext2; /tmp — /dev/mtdblock3 jffs2. Перенос убирает операции IPC-каталога из внутренней flash; это не означает отсутствие других записей на flash/CF. Старые файлы /tmp не удалялись автоматически.

Установлен кандидат v2026.02.03 unified-ipc, SHA256 ab77cee576abbf8bf2e63ec28f04938cc4a36584184612897812a6cfb578c081, 1151223 байта. Установщик завершился result=0 stage=verify-installed, failure_stage=none. Четыре установленных бинарника сверены по SHA256 с архивом.

HTTP до штатного перезапуска: 200, 64551 байт, 0,031 с. После stop/start: 200, 64551 байт, 2,047 с для первого запроса. Это отдельные наблюдения, не статистика производительности. На остановке socket исчез, после запуска появился /var/4vrs-web-ipc/1320.sock, подтверждён /proc/net/unix. Старые пустые lock-файлы остаются в RAM до перезагрузки.

RNG ready/schema3: поколение16 до установки,17 после установки,18 после stop/start. Повторная активация и удаление маркеров не выполнялись. gateway.conf, /etc/network/interfaces и подтверждённый сетевой профиль сохранили исходные хеши. Gateway оставлен работающим.

Локально прошли полный HTTP/TLS integration и восстановление после SIGKILL с сохранением постороннего объекта. Физическое отключение питания, повторная авторизация на приборе и трафик UART этим тестом не проверены. На Moxa #1/#2 кандидат не устанавливался. Linux2.4 имел отдельный успешный ограниченный Web-тест; полный установщик для него ещё не квалифицирован.

Первичные локальные результаты: outputs/moxa3-unified-ipc; outputs/unified-ipc-integration.log; outputs/unified-ipc-restart.json. Публикация не выполнялась.
