# v2026.01.01

Исправлена совместимость автоматического установщика. Корректные комментарии/
пустые строки перед существующим clock guard в start-ветке и строка Usage в echo
могли вызвать безопасный отказ до установки. Теперь распознаются эти ограниченные
формы с сохранением байтов/прав скриптов, сервера и PATH. Команды/вложенность вне
поддерживаемой структуры, дубликаты guard и незащищённые clock writers отклоняются.
Это не универсальный shell parser и не изменение NTP runtime.

Установщик и подсветка появились в v2026.01.00. Для патча аппаратно проверены
managed update, сохранность настроек, повтор без изменения процессов/файлов и
Modbus unit8/function4:3/3 до, после и после повтора. Новых reboot/NTP/физических
проверок подсветки не было; доказательства прежних версий сохраняют свои границы.

Скачайте `4vrs-gateway-v2026.01.01.tar.gz` и `SHA256SUMS`, выполните
[установку](../installation.ru.md). Размер пакета 225757 байт; SHA256
`2009f886c8efae678548f609642ed8e5158f1c29add3fcc4a94f19a18d736faf`.

Первое развёртывание, absent/late CF, физическое отключение питания при записи и
оставшиеся DHCP/DNS/route/affinity/crash сценарии аппаратно не подтверждены.
Владелец согласовал выпуск с этими ограничениями и отложил проверки с резервным
носителем; новое требование запасной CF не вводится. [Границы](../validation.ru.md).
Прежние релизы/assets не изменяются. Web остаётся будущим этапом.
