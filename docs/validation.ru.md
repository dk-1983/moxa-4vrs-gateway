# Границы проверок — v2026.01.00

[English](validation.md) · [Примечания к выпуску](releases/v2026.01.00.ru.md)

Выпуск использует неизменный проверенный пакет installer/Gateway. Владелец
разрешил публикацию с явно сохранёнными ниже непройденными границами.
Это не полная аппаратная квалификация и не универсальная поддержка любых vendor
layouts. v2026.00.01 не меняется. Публикация не означает обновление устройств.

| Область | Доказательства и границы |
| --- | --- |
| Host/сборка | 22 host-набора; релевантные UBSan application/panel/persistence/clock provider/installer; 9 package-тестов; полные XScale ELF и аудит ABI обоих бинарников |
| Managed update | Реальная нативная установка, сохранение собственных network/serial/NTP/store; исправный повтор без перезапуска служб и переписывания установленных файлов |
| Подсветка | Пользователь видел On/Off, навигацию при Off, сохранение и обычную перезагрузку с Off, затем включил On |
| Immediate recovery | Одно точное instrumented-прерывание publish-application, independent recovery и возврат исходного recovery ELF при доступной CF |
| Boot recovery | Одна отдельно разрешённая перезагрузка после точной границы без manual recovery перед ней; CF доступна, корректное поколение rollback, before-set восстановлен, службы запустились, TCP3/3; старый result100 не является результатом boot |
| Native observer | Положительный случай прошёл на target; stale/reused/zombie/live/error дополнительно проверены локально, не каждый отдельно на устройстве |
| Прежние сеть/время/serial | Выбранные LAN/mask/Keep/Revert, DHCP acquisition/renewal/expiry/recovery, RTC/NTP, Modbus-чтения и RAW loop на прежних ревизиях продукта; исходные границы не расширяются |

Instrumented-прерывание использует production orchestration/recovery с отдельной
qualification-границей. Это не снятие питания и не доказательство всех crash-фаз.
TCP connect не равен чтению Modbus/прибора; последние проверки второй Moxa — TCP.
Console reboot capture не содержит полного trace ранней загрузки.
[Манифест](releases/v2026.01.00-evidence.json) фиксирует хеши исходников, артефактов
и рассмотренных доказательств без публикации полных конфигураций.

## Явно не проверено / отложено

- Настоящее первое развёртывание на системе без Gateway, намеренно absent/late CF
  и физическое отключение питания во время durable-записи аппаратно не проверены.
  Владелец отложил сценарии с восстановительным носителем: имеются только две CF
  в работающих устройствах. Покупка запасной CF, разрушение установки или factory
  reset для этого выпуска не требуются. Эти проверки не объявлены пройденными.
- Сохраняются границы DHCP cancellation/late ACK, NAK/conflict/foreign-client,
  независимых LAN/двух клиентов; реальных DNS lookup после изменений и automatic
  DHCP-DNS publication/withdrawal; альтернативного route/interface; mask Keep/reboot
  и expanded-subnet; dedicated listener-affinity, обычных bind edits; других
  network durable Keep/crash-фаз. Это ограничения покрытия, не новые найденные баги.
- Многодневные прогоны, точная latency/packet capture NTP и дополнительные RTC
  readback — необязательные расширения, а не новые обязательные барьеры выпуска.

Позднейшие разрушительные/зависящие от носителя тесты требуют своего плана
восстановления и разрешения оператора. Web отложен на следующий этап.
