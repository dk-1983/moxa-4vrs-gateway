# v2026.01.00

Native automatic installation and persistent display backlight control for
Moxa UC-7420-LX Plus. Download the complete `4vrs-gateway-v2026.01.00.tar.gz`
package and `SHA256SUMS`; follow [installation](../installation.md).

- Run `./4vrs-install` on the Moxa; device-specific network, serial and NTP
  settings are retained. Read the saved result with `./4vrs-install --status`.
  A healthy repeat avoids unnecessary service restarts. Independent recovery
  protects unfinished transactions; no automatic reboot occurs.
- **System → Display → Backlight → On / Off**: default On, F3 saves, restored
  at startup. Display/key handling remains available with light Off.
- Managed update/no-op, physical backlight and normal reboot passed. One exact
  instrumented immediate recovery and one CF-present boot recovery also passed;
  this is not all crash phases or full hardware qualification.

**Limits:** real first deployment, absent/late CF and physical write-power
interruption remain hardware-unverified. Media-dependent tests are deferred by
the owner because no spare CF is available; no destructive teardown is required
for this release. Other DHCP/DNS/route/affinity and network crash coverage stays
open as detailed in [validation](../validation.md), not newly discovered bugs.
Older decoders cannot read saved Off fields; review configs/backups before downgrade.
Web remains a future release. v2026.00.01 assets are unchanged.
