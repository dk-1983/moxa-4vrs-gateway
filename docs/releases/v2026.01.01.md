# v2026.01.01

Compatibility fix for the automatic installer. Valid comments/blank lines before
an existing start-branch clock guard and a literal Usage echo could previously
cause a safe refusal before installation. The installer now recognizes these
narrow forms and preserves accepted script bytes/modes, server and PATH.
It still rejects unsupported commands/nesting, duplicate guards and unprotected
clock writers. This is not a general shell parser or an NTP runtime change.

Installer and backlight control were introduced in v2026.01.00. This patch was
hardware-checked for managed update, settings preservation, healthy repeat with
stable processes/files and actual Modbus unit8/function4 reads3/3 before, after
and after repeat. New reboot/NTP/backlight physical checks were not performed;
earlier version evidence retains its original scope.

Download `4vrs-gateway-v2026.01.01.tar.gz` and `SHA256SUMS` and follow
[installation](../installation.md). Package: 225757 bytes, SHA256
`2009f886c8efae678548f609642ed8e5158f1c29add3fcc4a94f19a18d736faf`.

First deployment, absent/late CF, physical power loss during writing and remaining
network DHCP/DNS/route/affinity/crash coverage remain hardware-unverified.
The owner authorized release with these limits and deferred recovery-media tests;
no new spare CF requirement is imposed. [Validation scope](../validation.md).
Previous releases/assets are unchanged. Web remains a future stage.
